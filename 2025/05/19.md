### 💡 What I noticed / learned
- `docker run -it ubuntu bash`  
  - `docker run` first looks for the image on the host; if found, it starts the container, otherwise it pulls from Docker Hub and then starts it.  
  - In this case, it launches an Ubuntu container and runs `bash` inside it—i.e. you’re running `bash` on the Ubuntu OS within the container.
